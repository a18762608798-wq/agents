# Paper 写作与事实核验

## 独立写作，使用已有实验产物

Paper 是 Exp 的下游。论文写作通过独立 skills 进行，不要求 Paper spec、plan、tasks、
paper-XX 或固定阶段验收。唯一论文规划文件是项目的 docs/planning/paper-outline.md。
普通段落、章节顺序和主附录调整直接改稿；主线、核心主张或数据需求变化时再维护大纲。

Exp spec 和真实产物记录本项目实际计算或测量了什么。Dxx/Sxx 的编号、定义与归属
沿用已有实验映射和规范，不能因论文章节重排而重新编号、复用或改写。
实验笔记只记录核心理论：模型、定义、符号、假设、公式与必要推导；读取位置以 docs/README.md 为准。
实验定义和执行状态归 Exp；文献支撑关系归引用核验记录，具体边界见下文。
笔记的存在不等于其推导已充分、适用条件已核验，不能直接把简记当成投稿稿件。

## 先核实依据，再组织理论正文

从拟写章节或理论问题出发，查找并阅读原始论文、权威综述或教材的相关全文。
寻找论文使用 gamma-paper-hunter；寻找书或讲义使用 gamma-book-hunter；
只检索库内已有条目时直接使用 Gamma 的 `search_library`、`list_pages` 和 `read_page`。技术引用需经过 paper-gamma-hunter 的全文核验。

记录来源的 `workspace_id`、Gamma Page ID/绝对链接、页码/章节/公式位置、支持的具体论述及适用条件。
书或讲义可能没有 DOI，应按其可靠元数据和所读内容引用。
只有元数据或摘要时，不据此确认具体技术结论。

依据已核验来源独立组织定义、解释和必要推导，保留合理的正确公式。
参考权威写法并不表示复制段落或强行让项目公式与文献表面一致。
明确区分文献已有结论、本项目采用的约定、自己的构造及新的推导。

核对算符、符号、单位、边界条件、参数化、归一化、近似和适用范围。
仅当这些差异影响理解或结果时保留必要的等价关系说明，不为每个公式新增规范 ID。

## 科学限定与防御性措辞

直接陈述研究问题、定义、方法和实际结果，让每个判断都有具体内容。
科学限定说明论断成立的假设、研究对象、适用范围、统计口径，或影响结果解释的实质局限。
这些内容是论证的一部分，放在对应的定义、方法或结果处；摘要中的关键数字也应能辨认其统计口径。
例如，“该界适用于扇区内基态唯一的归一化试探态”给出了必要条件，应保留。

防御性措辞没有增加必要事实，却反复替工作降格、预先回应假想批评，或把内部核验备注写成正文。
已说明条件后再机械追加“不能证明”“不保证”“仅供参考”，应按实际语义删除或改写。
判断依据是信息作用，不是否定词：必要的否定结论、数学事实和实质局限照实表述。
自我限制与防御性措辞不等同；不规定每篇必须有几句自我限制，也不要求给每个被引工作列缺点。

修改语气时保留真实结果、不确定度及影响解释的条件，保持论断与证据范围一致。
文献支撑证据及其缺口在引用核验记录中维护；评审问题按本轮范围报告。影响读者理解的科学内容仍应在论文中交代。
结果或后处理更新时，同步检查摘要、引言、结果、结论和图注，避免旧结论残留。

## 引用证据与工作记录

引用核验记录按来源和具体论述维护当前有效的支撑关系：cite key（如已有）、
`workspace_id` 与 Gamma Page ID/链接、所读版本与页/节/公式位置、支持内容、适用条件、核验结论及正文或计划绑定位置。
缺少全文或精确定位时如实标注，不把记录整理当作重新核验。
已有记录则沿用；首次保存文献证据时按项目约定建立紧凑索引，不指定统一文件名，不按任务另建台账。

新增来源、重读核验或被引论述范围变化时，更新对应条目；证据缺口就地维护，解决后更新状态。
修订历史通过 Git 查看；整理旧记录前保留尚未提交的有效证据，避免以清理日志为由丢失来源支撑。
实验定义、参数、运行及验收结果引用已有 Exp 规范和正式产物，不在引用记录复制维护。
日常措辞、符号或排版修改无需更新引用记录；改动、检查和剩余问题在本轮回复中简要说明。
编译和验证明细沿用已有运行产物，按实际追溯需要保存，不自动追加永久工作日志或另建审计目录。
用户明确要求修订报告或审阅报告时，按指定范围交付；该报告与文献支撑索引分别维护。

## 证据与缺件

所有实验数字、图和结果解释必须可追溯，不编造数据、引用或验证状态。
来源只支持其实际内容，不能用相近论文替本项目特有公式背书。
自行推导应说明前提和推导过程，相关文献可以支持其基础，但不能伪装成直接出处。

在本轮回复中区分实验数据/图缺失、文献或理论证据缺口，以及尚未验证的解释；文献缺口同时更新受影响的来源条目。
明确标识待办或暂缓受影响段落，允许无关部分继续；未确认的猜测不能写成事实。
编译通过或引用 key 存在，不能证明科学正确性、文献支撑关系或整篇完成。

发现笔记、公式或实验口径可能有误时，停止受影响段落并返回 Exp 层核查。
Paper 技能可提出实验或分析需求，但不得静默修改实验定义、代码、数据或结果含义。

## 工程约定

稿件位于 docs/paper/；规划和固定路径以 docs/README.md 为准。
文献元数据来自已核验的 Gamma Page 原生属性，不臆造 BibTeX 字段。
现有标签和 cite keys 没有必要时保持稳定；论述发生实质变化时重新核验引用。
仅修改措辞时，核对 TeX 源码、引用和交叉引用并编译即可。
仅在用户要求、只有 PDF 输入或存在具体版面问题时追加本稿 PDF 检查；不默认提取或逐页审阅 PDF。
这不替代新增理论和引文所需的来源核验，也不改变文献全文阅读要求。
遵守项目环境、数学排版、文件移动和回收站约定，不额外安装全局环境或修改宿主配置。
